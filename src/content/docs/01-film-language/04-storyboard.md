分镜脚本（storyboard）是把剧本翻译成画面的中间环节。**对 AI 漫剧来说，分镜表就是你的施工图**——填满它，然后一行一行翻译成提示词。

## 标准分镜表有哪些字段

| 字段 | 英文 | 说明 | 示例 |
|---|---|---|---|
| 镜号 | Shot Number | 按顺序编号，方便沟通和返工 | Sc.1-1（第 1 场第 1 镜） |
| 景别 | Shot Size | 远景/全景/中景/近景/特写 | 中近景 |
| 角度 | Camera Angle | 平视/俯拍/仰拍/过肩/POV | 低机位仰拍 |
| 镜头运动 | Camera Movement | 推/拉/摇/移，含速度 | 缓慢推近 |
| 画面内容 | Visual Description | 人物位置、动作、表情、背景、光线 | A 坐在沙发上转向 B，泪水滑落 |
| 台词 | Dialogue | 这个镜头里说的话 | "我一直都爱你" |
| 音效/配乐 | Sound / Music | 环境音、特效音、BGM | 细雨声，悲伤弦乐 |
| 时长 | Duration | 这镜多长 | 3 秒 |

## 完整范例：五镜头对话戏

场景：咖啡厅，A 向 B 告白失败后的尴尬时刻。

| 镜号 | 景别/角度 | 运镜 | 画面描述 | 台词 | 音效 | 时长 |
|---|---|---|---|---|---|---|
| Sc.1-1 | 中景 / 平视 | 固定 | A 和 B 坐在靠窗桌前。A 低头看杯子，B 转向窗外。两人都很安静，背景是模糊的午后阳光 | （无） | 咖啡厅环境音、杯子碰撞声 | 2s |
| Sc.1-2 | 近景 / 平视 | 缓慢推近 | 镜头推向 A 的脸。A 深吸一口气，眼神湿润，嘴角微微颤动 | A：我……不应该说那些话 | 轻微哀伤的钢琴 | 2s |
| Sc.1-3 | 中近景 / 仰拍 | 固定 | 从 B 的下方往上拍，B 转向 A。表情复杂，既有怜悯又有些冷淡，光线打在脸上显出线条感 | B：有些话一旦说出来，就回不了头 | 钢琴加弦乐 | 3s |
| Sc.1-4 | 过肩 / 平视 | 缓慢右移 | 从 A 的肩后拍，A 低着头，背景是 B 转身的身影，A 的手紧握咖啡杯 | A：我知道 | 环境音，音乐淡出 | 2s |
| Sc.1-5 | 全景 / 俯拍 | 镜头上升 | 镜头升起，两人坐在空荡的咖啡厅里，阳光透窗打下，整体冷蓝调 | （无） | 悲伤主题渐弱 | 2s |

看这张表的节奏：**中景交代 → 近景给 A 的情绪 → 仰拍给 B 的压制感 → 过肩表现关系 → 升镜拉远收尾**。五个镜头，景别、角度、运镜没有一个重复。

## 怎么翻译成 AI 提示词

分镜表的每一行都可以独立变成一条提示词。以 Sc.1-2 为例：

```
近景，平视机位，镜头缓慢推近女性角色的脸。她深吸一口气，眼眶湿润，
嘴角微微颤动，睫毛轻轻发抖。背景是虚化的咖啡厅内景，午后阳光柔和。
（哀伤的钢琴独奏）{我……不应该说那些话}
电影级画质，光影柔和，人物面部稳定不变形。保持无字幕，不要生成水印。
```

对照关系：

| 分镜字段 | 提示词里对应的位置 |
|---|---|
| 景别 + 角度 | 开头第一句 |
| 运镜 | 紧跟景别 |
| 画面描述 | 主体部分，动作要拆到具体肢体 |
| 音效/配乐 | 用 `（）` 包住音乐、`<>` 包住音效 |
| 台词 | 用 `{}` 包住 |
| 时长 | **不要写进提示词**（见下方警告） |

:::caution[时长不要写进提示词]
官方文档明确说：

> 模型对精确时间（如 0–3 秒）的支持不稳定，强行限制时长可能导致生成结果异常。

时长在分镜表里记录、在参数里设置，**别写进提示词正文**。
:::

## 一个省事的做法

Seedance 2.0 支持**一条提示词里写多个分镜**，用「镜头1／镜头2／镜头3」标序。所以上面五行不一定要生成五次——可以三镜合一条，生成一个 15 秒的连续片段。详见[分镜时序写法](/02-prompt-engineering/shot-sequence/)。
