**这一页是整份指南使用频率最高的东西。**

原因是官方文档明确要求的：

> 用具体的身体细节表现情绪，替代"很悲伤""非常愤怒"这类抽象词汇。

模型不理解"愤怒"，但它见过无数"攥紧的拳头、绷紧的下颌线"。你的工作是**把情绪翻译成可拍摄的身体动作**。

## 官方给的五种（原文照抄）

火山引擎 Seedance 2.0 文档里直接给了这张对照表：

| 抽象情绪 | 官方给的外化写法 |
|---|---|
| **悲伤** | 低头、肩膀微微颤抖、眼眶泛红、手指无意识地攥紧衣角、泪水在眼眶里打转但没有落下 |
| **喜悦** | 嘴角抑制不住地上扬、眉眼舒展、脚步变得轻快、下意识地哼起小曲、忍不住原地转个圈 |
| **紧张/焦虑** | 频繁地看手表、手指不停敲击桌面、呼吸急促、眼神闪躲、无意识地啃咬指甲 |
| **愤怒** | 双拳紧握、下颌线紧绷、胸口剧烈起伏、眼神如刀般锐利、从牙缝里挤出话语 |
| **释然** | 长长地舒了一口气、紧绷的肩膀完全放松下来、脸上露出久违的、淡淡的微笑、抬头望向远方 |

这五条是**官方原文**，可信度最高，可以直接抄进提示词。

## 肢体语言的空间含义

除了单个动作，**人物之间的空间关系**本身就在表意：

| 对立面 | 含义 |
|---|---|
| **靠近 vs 远离** | 靠近＝信任、亲密、对抗、渴望；远离＝厌恶、恐惧、防御、拒绝 |
| **面向 vs 转身** | 面向＝参与、关心、挑衅；转身＝拒绝、失望、逃离 |
| **手臂张开 vs 交叉** | 张开＝开放、接纳、坦诚；交叉＝防御、冷漠、自我保护 |
| **眼神接触 vs 避开** | 接触＝诚实、挑衅、亲密；避开＝内疚、羞愧、说谎 |

写提示词时，**一句空间关系抵得上三句表情描写**。比如"她转过身背对他"比"她很失望"有效得多。

## 官方对动作描述的四条要求

Seedance 2.0 文档还规定了动作该怎么写：

1. **肢体细化 + 程度量化**：动作要具体到手、腿、头部、肩背，并补充幅度、速度、力度。示例：缓慢抬手、快速转头、用力蹬地、微微低头。
2. **优先低缓连续小动作**：官方原文说要"尽量规避狂奔、大跳、剧烈翻滚等高爆发、大动态动作"。示例：缓慢行走、轻轻抬手、顺势坐下。
3. **补充动作过渡衔接**：写明前后动作的承接关系。示例：借着转身惯性顺势抬手。
4. **情绪具象外化**：就是本页这张表。

:::caution[第 2 条对漫剧特别重要]
很多人一上来就写"男主一拳打飞对手"，结果生成出来手脚扭曲。**AI 视频模型现阶段处理大动态就是不稳**。漫剧里的打戏，用"缓慢握拳 + 镜头快速推近 + 切黑场"这种**留白手法**，比硬生成打斗成功率高得多，也更有漫画感。
:::
