运镜是新手最容易写错的部分——不是词写得不好，是**根本分不清哪个词对应哪个动作**。

先看官方支持的词。火山引擎 Seedance 1.0 文档原文：

> 精准响应**推、拉、摇、移、环绕、跟随、升、降、变焦**等运镜指令。

Seedance 1.5 Pro 又补了两个：**甩、旋转**。

## 基础运镜词表

| 运镜 | 镜头在做什么 | 情绪含义 | 官方示例写法 |
|---|---|---|---|
| **推** | 摄影机整体向前移动，靠近主体 | 聚焦、逼近、情绪收紧 | `镜头快速前推到小女孩的近景` |
| **拉** | 摄影机整体向后移动，远离主体 | 抽离、揭示全貌、情绪释放 | `镜头快速拉远，露出女子上半身` |
| **摇** | 机位不动，机身左右转动 | 环视、扫描、跟随视线 | `镜头右摇侧面拍摄一个衣着华丽的模特` |
| **移** | 摄影机整体平行移动 | 陪伴、并行、展示纵深 | `镜头右移展示长城的雄伟壮丽` |
| **跟随** | 摄影机跟着主体一起走 | 代入、紧迫、参与感 | `镜头跟随飞翔的狮子` |
| **升** | 摄影机垂直上升 | 抽离、俯瞰、收尾感 | `镜头逐渐升起，露出登山者的背影` |
| **降** | 摄影机垂直下降 | 沉入、压迫、逼近地面 | 与「升」反向 |
| **环绕** | 摄影机绕着主体转 | 展示、强调、仪式感 | `镜头环绕拍摄，从女人的背面到正面` |
| **变焦** | 机位不动，镜头焦距变化 | 突兀、强调、窥视感 | `变焦镜头下，镜头推近被告紧张的面容` |
| **甩** | 快速摆动 | 转场、慌乱、冲击 | 常用于镜头间过渡 |
| **旋转** | 镜头绕自身轴线转 | 眩晕、失衡、梦境 | `镜头围绕主体做360度旋转` |

## 两对最容易搞混的

### 「推」 ≠ 「变焦」

这是新手第一大坑。

- **推**：摄影机**真的往前走**。人和背景的相对关系会变——前景越来越大，背景被"甩"到后面，有真实的空间纵深感。
- **变焦**：摄影机**站着不动**，只是镜头焦段变了。整个画面被均匀放大，像"裁切"，背景和主体一起被压扁，空间感是假的。

**什么时候用哪个**：想让观众感觉"走进这个空间"，用推；想制造一种突兀的、被强行拉近的窥视感，用变焦。

把这两个反向组合起来，就是著名的**希区柯克变焦**（滑动变焦）——一边推一边反向变焦，主体大小不变但背景疯狂扭曲，用来表现眩晕、认知崩塌。Seedance 1.5 Pro 官方文档直接给了公式：

> 希区柯克镜头 = 推拉 + 变焦

### 「摇」 ≠ 「移」

- **摇**：三脚架不动，**机身在原地转头**。像人站着不动转脖子。
- **移**：整个摄影机**平行滑过去**。像人一边走一边看。

差别在于**有没有位移**。摇的时候近处的东西会快速划过、有畸变；移的时候前后景会产生视差，纵深感更强。

## 高级质感怎么写

「手持」不是一个官方关键词——官方文档里从来没出现过这个词。正确做法是**用自然语言描述效果**，官方案例的写法是：

```
手持镜头向前快速跟拍，画面带有轻微真实的晃动感
```

同理，「斯坦尼康」这类设备名模型也不一定认，写成「镜头平稳跟随，无晃动」更保险。

Seedance 1.5 Pro 还给了另一个组合公式：

> 子弹时间镜头 = 升格镜头 + 快速环绕

## 官方运镜写法公式

Seedance 1.5 Pro 文档给了一条完整的运镜描述公式：

> 起幅构图描述 + 运镜 + 运镜幅度 + 落幅构图描述

翻译成人话就是：**从什么画面开始 → 怎么动 → 动多大 → 停在什么画面**。

例如：

```
中景，男人站在门前 + 镜头缓慢推近 + 幅度轻微 + 停在他眼部的特写
```

## 铁律：一个镜头只写一种运镜

这条是官方明确警告的，原文：

> 一个镜头里尽量只指定 1 种运镜方式，不要同时要求推拉摇移，会增加画面的不稳定性。

想要复杂运镜就拆成多个镜头，别塞在一句话里。
