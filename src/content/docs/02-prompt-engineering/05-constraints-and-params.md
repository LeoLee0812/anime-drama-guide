## 约束词：官方说它「十分重要」

官方原话就是这么写的：

> **约束词**：十分重要，可有效规避画面瑕疵、畸形崩坏及不合理元素。

**常用约束词模板（官方原文）**：

> - 避免生成字幕："保持无字幕"、"避免生成任何文字或字幕"
> - 避免生成 Logo："不要生成Logo"
> - 避免生成水印："不要生成水印"

漫剧场景建议在每条提示词末尾固定加这一串：

```
人物面部和身体比例稳定不变形，动作连贯自然，无穿模无卡顿。
保持无字幕，避免生成任何文字，不要生成水印或Logo。
```

多角色同框时再补一句防双胞胎的（官方原文）：

```
视频全程禁止出现外形、着装、配饰完全一致的人物，禁止生成同款分身、双胞胎效果。
```

## 画质词与风格词

官方给的示例：

- **画质**：`高清，细节丰富，电影质感，色彩自然，光影柔和`
- **风格**：`赛博朋克冷蓝紫色调、复古胶片、日系清新`

官方对画质词的定位是「定义画面清晰度、细节纹理与光影质感，提升成片基础画质」——**是个加分项，不是必需项，别堆太多**。

## 画幅

Seedance 1.0 官方支持的比例：

> **1:1，3:4，4:3，16:9，9:16，21:9**

图生视频的官方建议：

> i2v 建议用这些比例的图片作为参考帧，假如不是这些比例的话，自动匹配会通过裁切来适配最接近的比例。

:::tip[横屏能少踩一个坑]
官方在字幕问题里给了一条很实用的建议：

> 在业务允许的前提下，优先选择横屏尺寸生成视频（**横屏生成字幕的概率明显低于竖屏**），后续可通过剪辑软件裁剪为竖屏。

漫剧最终要发抖音（9:16），但如果你被乱码字幕折磨，可以**先用 16:9 生成再后期裁成竖屏**。
:::

## 时长

Seedance 2.0 的 `duration` 参数支持 **4–15 秒连续区间**，不是固定挡位。参考视频输入时，最多 3 段视频且总时长不超过 15 秒。

**再强调一次**：时长通过参数设置，**不要写进提示词正文**。

## API 参数表

如果你走火山引擎 API 或 dreamina CLI 而不是网页端：

| 参数 | 说明 | 取值 |
|---|---|---|
| `resolution` | 分辨率 | 480p / 720p / 1080p / 4k |
| `ratio` | 宽高比 | 16:9 / 9:16 / 1:1 / 3:4 / 4:3 / 21:9 |
| `duration` | 时长（秒） | 4–15 |
| `seed` | 随机种子 | 整数，固定它可复现同一结果 |
| `camera_fixed` | 是否固定机位 | true / false |
| `watermark` | 是否加水印 | true / false |

**新写法**（推荐）——直接放在请求体里：

```json
{
  "model": "doubao-seedance-2-0-260128",
  "content": [{ "type": "text", "text": "小猫对着镜头打哈欠" }],
  "resolution": "720p",
  "ratio": "16:9",
  "duration": 5,
  "seed": 11,
  "camera_fixed": false,
  "watermark": true
}
```

**旧写法**——在提示词末尾追加：

```
小猫对着镜头打哈欠 --rs 720p --rt 16:9 --dur 5 --seed 11 --cf false --wm true
```

:::note[seed 是省钱利器]
固定 `seed` 可以复现同一次生成结果。抽到一个构图不错但细节有小毛病的结果时，**锁住 seed 只微调提示词**，比重新抽卡便宜得多，也更容易保持跨镜头的一致性。
:::

## 文字生成（如果你真要在画面里出字）

官方给了模板：

> 「文字内容」+「出现时机」+「出现位置」+「出现方式」，「文字特征（颜色、风格）」

并提醒：

> 优先使用常用字，避免生僻字与特殊符号，以确保最佳呈现效果。

但对漫剧来说，**标题和字幕交给剪映做，成功率比让模型画字高一个数量级**。
