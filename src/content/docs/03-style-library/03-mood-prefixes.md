## 九种氛围的整句写法

抽象情绪要翻译成**画面词的组合**。下面每一行都可以整句复制。

| 氛围 | 可直接粘贴的中文表述 |
|---|---|
| **悬疑** | `画面笼罩在阴影中，昏暗的角落，薄雾弥漫，光影诡异，人物表情紧张不安，整体冷调压抑` |
| **压抑** | `沉闷的灰蒙色调，低对比度，阴天柔光，破旧纹理清晰，空间显得逼仄，暗角压低视觉` |
| **治愈** | `温暖的黄金时刻光线柔和洒下，背景清爽通透，人物面带微笑，色彩温馨明亮，氛围宁静` |
| **燃/热血** | `光影对比强烈，色彩鲜艳炽热，人物动作有力，能量感强烈，画面充满冲击力` |
| **克制/内敛** | `极简的画面构图，单一柔和色调，细微的表情变化，环境安静，光影极其细腻` |
| **荒诞** | `色彩组合违背常理，透视角度扭曲，物体摆放不合逻辑，超现实氛围，令人不适的违和感` |
| **浪漫** | `柔焦画面，粉调暖光，花瓣缓缓飘落，人物靠近温柔对视，细节充满暖意` |
| **孤独** | `纯白与冷蓝的色调，远景中人影孤立，清冷的光线没有温度，空旷的空间，沉默感` |
| **神秘** | `朦胧逆光，人物面部隐没在阴影中，浓紫蓝色调笼罩，光晕闪烁，看不清面容` |

这些属于通用美术经验，不是官方文档内容——**好用但请自己验证**。

## 用法铁律

**全剧所有镜头，风格前缀必须一字不差地重复。**

这是多篇创作者教程反复强调的同一条经验——画风漂移的头号原因就是每次生成时风格描述写得不一样。把你选定的前缀存成一个文本片段，每次生成先粘它，再写正文。

:::tip[前缀不要太长]
风格前缀控制在 30 字以内。官方警告过提示词过度冗余会造成模型理解混乱，风格词占太多篇幅会挤掉动作和运镜的权重。
:::
