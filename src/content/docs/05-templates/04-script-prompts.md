这一页的提示词**不是给视频模型的**，是给文本大模型的——用来生成剧本、拆人物、转分镜。

以下几条来自创作者教程的原文，可直接复制。

## 剧本生成指令

创作者原文模板：

```
你是一位抖音短剧的金牌编剧，特别擅长写"重生复仇"题材的爽文。
现在，请你帮我创作一个1分30秒的AI漫剧脚本。

1. 故事核心：女主被闺蜜和丈夫联手背叛，含恨而死，重生回到自己的订婚宴上。

2. 创作要求：
- 黄金3秒：必须有一个强烈的视觉和听觉钩子（如一声清脆的耳光）。
- 30秒反转：出现第一个打脸情节，释放观众情绪。
- 节奏要求：冲突密集，情绪像过山车。

3. 输出格式：请按【序号】-【画面描述（Prompt）】-【角色台词】-【音效】格式输出，
方便我直接导入即梦AI制作。
```

出处：[知乎 · 零基础AI漫剧全流程拆解](https://zhuanlan.zhihu.com/p/2012466186349209444)

**这个模板好在哪**：它把「角色设定 + 节奏要求 + 输出格式」三件事一次性交代清楚了。尤其是最后的输出格式——**指定格式能省掉大量手工整理**。

### 换题材怎么改

把三处替换掉即可：

| 位置 | 换成 |
|---|---|
| 题材标签 | 都市异能 / 校园治愈 / 悬疑推理 / 古风宅斗 |
| 故事核心 | 你自己的一句话设定 |
| 黄金 3 秒钩子 | 对应题材的爆点（异能觉醒 / 意外撞见 / 尸体出现） |

## 人物档案指令

```
基于上面的剧本，为每个出场角色生成一份人物档案，包含：
- 姓名、年龄、身份
- 性格关键词（3个）
- 外形特征：发型、发色、眼型、脸型、身高体型（写肉眼可见的固定特征，
  不要写"气质出众"这类抽象描述）
- 服装：颜色、款式、配饰
- 音色描述：性别 + 年龄区间 + 声音属性 + 语速 + 情绪基线

要求：外形特征必须具备唯一可识别性，能把这个角色和其他角色区分开。
```

**音色那一行是按 Seedance 1.5 Pro 的官方公式写的**，产出的描述可以直接用在视频提示词里。

## 分镜转换指令

创作者原文：

```
请将以下剧本改写为分镜头脚本，包含镜头序号、景别（远景/中景/近景/特写）、
画面内容描述、时长（每个镜头3-5秒）、台词或音效备注。
```

出处：[知乎 · 豆包+即梦实操](https://zhuanlan.zhihu.com/p/1998082469233174368)

### 加强版（推荐用这个）

上面那条会生成一堆中景。加上约束会好很多：

```
请将以下剧本改写为分镜头脚本，输出为表格，包含以下字段：
镜号 | 景别 | 机位角度 | 镜头运动 | 画面内容 | 台词 | 音效 | 时长

约束要求：
1. 景别必须穿插变化，不允许连续两个镜头使用相同景别，
   全片必须包含至少一个远景、一个特写。
2. 每个镜头只指定一种镜头运动，不要组合运镜。
3. 画面内容里的情绪必须写成具体的身体动作，
   例如不写"她很悲伤"，写"她低头，肩膀微微颤抖，手指攥紧衣角"。
4. 对话镜头按每秒2.5个字估算时长，确保台词说得完。
5. 全片镜头数控制在 8-12 个。
```

这四条约束分别对应[景别穿插](/01-film-language/01-shot-sizes/)、[一镜一运镜的官方铁律](/01-film-language/02-camera-movement/)、[情绪具象化](/01-film-language/07-emotion-to-action/)和台词字数限制——**把规则前置到分镜阶段，比事后一条条改省事得多**。

## 分镜转提示词指令

拿到分镜表后，让大模型批量转成视频提示词：

```
请把下面的分镜表逐条转换成视频生成提示词，规则如下：

1. 每条提示词以这个风格前缀开头（一字不改）：【粘贴你的风格前缀】
2. 结构顺序：景别与运镜 → 人物动作与表情 → 场景环境 → 光影色调
3. 台词用 {} 包裹，音效用 <> 包裹，背景音乐用（）包裹
4. 不要写秒数或时间点
5. 每条结尾统一加上：人物面部和身体比例稳定不变形，动作连贯自然，
   无穿模无卡顿。保持无字幕，避免生成任何文字，不要生成水印或Logo。
6. 情绪一律写成具体身体动作，不使用抽象情绪词

分镜表：
【粘贴你的分镜表】
```

## 一个官方警告

:::caution[别把剧本直接当提示词]
官方原文：

> 请勿直接将完整剧本作为提示词使用，文案内容过度冗余易造成模型理解混乱，需精简无关表述、保证指令清晰聚焦。

剧本是给你自己看的，提示词是给模型的。**中间必须经过分镜表这一道压缩。**
:::

## 关于用哪个大模型

写剧本这一步对模型要求不高，DeepSeek、豆包、Claude 都够用。**豆包的优势是跟即梦同属字节**，生成的画面描述风格更贴近 Seedance 的理解方式；DeepSeek 胜在免费额度大、中文网文的语感好。
