角色卡是全剧的「身份证」。**这一步做好了，后面所有镜头的脸都稳；这一步偷懒，后面每一镜都在崩。**

## 每个角色要准备两张图

官方在「人物 ID 漂移」问题里给的方案：

> 准备人脸特写图：在原有全身照之外，额外准备一张只包含角色头部的人脸特写图（大头照，仅保留面部，无表情最佳，尽量减少肩颈、背景等干扰元素）。

所以标配是：

| 图 | 用途 | 要求 |
|---|---|---|
| **大头照** | 锁脸 | 只有头部，无表情最佳，减少肩颈和背景干扰 |
| **全身照 / 半身立绘** | 锁妆造和服装 | 单人独立，纯色背景，均匀平光 |

在提示词里分工写清楚，官方给的句式：

```
主体1的面部特征参考图片1（大头照），妆造参考图片2（全身照）
```

## 定妆照提示词模板

公式：**风格前缀 + 完整外形描述 + 纯色背景 + 无光影 + 单人构图**

### 男性角色

```
【你的风格前缀】，25岁亚洲男性半身正面立绘，短碎黑发额前微乱，
单眼皮细长眼，下颌线清晰，浅灰色衬衫袖口挽到小臂，黑色斜挎帆布包，
神情疲惫警觉，纯灰色背景，均匀平光无强烈光影，单人独立构图
```

### 女性角色

```
【你的风格前缀】，22岁亚洲女性半身正面立绘，黑色长发扎低马尾，
圆眼杏仁形，鼻梁小巧，米白色针织开衫内搭浅蓝衬衫，
神情温和略带疏离，纯灰色背景，均匀平光无强烈光影，单人独立构图
```

### 配套大头照

```
【你的风格前缀】，上面这个角色的面部大头照，正面平视，
面无表情，只保留头部，纯灰色背景，均匀平光，无肩颈无饰品
```

## 外形描述写什么

写**肉眼可见的固定特征**，不写气质形容词。

| ✅ 该写 | ❌ 别写 |
|---|---|
| 短碎黑发额前微乱 | 发型很有个性 |
| 单眼皮细长眼 | 眼神深邃 |
| 下颌线清晰 | 五官俊朗 |
| 浅灰色衬衫袖口挽到小臂 | 穿得很随性 |
| 左眉尾有一道小疤 | 有故事感 |

官方对特征描述的要求是：

> 使用 2–3 个清晰、稳定的静态特征（如服饰、发型、外观、类别）进行描述，确保唯一可识别性。

**「唯一可识别性」是关键**——这些特征要能把这个角色跟其他角色区分开。全剧都是黑发的话，"黑发"就不是有效特征。

## 三条硬性禁忌

:::danger[绝对不要做的三件事]
1. **不要出三视图。** 官方原文：「不建议使用人物多视图。多视图素材包含同一人物的不同角度，模型易将其识别为多个不同主体，反而加剧 ID 漂移问题。」
2. **不要把人脸和全身混在一张图里。** 官方说这会导致人脸占比过小、特征权重不够。
3. **不要用真人照片直接生成动漫视频。** 官方在「风格漂移」里说了，写实参考图会让结果漂成真人风格，要先把图转成目标风格。
:::

## 多角色怎么绑

官方给的格式是**在人名后面标注对应图片**，并保持格式统一：

```
张三（对应图片1）将绿色存折扔向站立的李四（对应图片2）
```

在即梦网页端则用 `@` 语法：

```
@图片1中的男人作为主角，@图片2中的女人作为对手
```

再加上防双胞胎的全局约束（官方原文）：

```
视频全程禁止出现外形、着装、配饰完全一致的人物，
禁止生成同款分身、双胞胎效果，同一画面中仅保留单个对应人物
```

**人数上限是 4**。官方说超过 4 人稳定性明显下降，6 个人要分成 2 组每组 3 人分别出图，再合成。

## 角色卡文档怎么存

建一个文本文件，每个角色一段，存好这些：

```
【角色名】林辰
【定妆照】~/漫剧/角色卡/林辰_全身.png
【大头照】~/漫剧/角色卡/林辰_大头.png
【提示词】2D日漫风格国漫质感，28岁亚洲男性，黑色长发发丝整洁，
         剑眉，眼神锐利，月白色锦袍，腰间半块白玉佩
【音色】男性，28岁左右，低沉沉稳的青年音，语速偏慢，情绪克制
```

每次生成新镜头，先把这段提示词粘上，再垫图。**跨集、跨天创作时，这个文件就是你不崩人设的唯一保障。**
